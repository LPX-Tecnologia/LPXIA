# LPX-NEXUS Architecture

## Overview

LPX-NEXUS is a modular AI platform composed of:
- Backend API built with FastAPI
- Frontend client built with Next.js and TypeScript
- PostgreSQL for persistence
- Redis for support services
- Docker Compose for local orchestration

## Core modules

- Authentication
- User management
- Long-term memory
- Agent orchestration
- Project workspace
- Deployment pipeline

## Design principles

- Clean architecture
- SOLID principles
- Modular services
- Test-first mindset
- Docker-first delivery
